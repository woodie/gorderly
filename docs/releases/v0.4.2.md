# gorderly v0.4.2

## Fix

`Render` indented every line one level too deep. The package import path
(e.g. `github.com/woodie/humane`) was being counted as a real parent node
in the tree, pushing the actual top-level `Test` function down to depth
1 instead of depth 0. Confirmed against raw `go test -v` output: the
import path never appears as a prefix of any `=== RUN` line -- it only
shows up once, disconnected, in the final `ok  <path>  (cached)` summary.
`kotidy` and `xctidy` both render their own top-level suite name flush
left, with no such wrapping level.

The package path still prints as the first line of output -- it's useful
context, especially for `go test -v ./...` across multiple packages --
but it no longer costs an indent level. Every line below it shifts up by
one.

## Notes

Purely a rendering fix -- `Parse` and the underlying `go test -v` parsing
are unchanged. If you were counting on the old (deeper) indentation in
scripts or diffs against `gorderly` output, expect every line to shift
left by two spaces.
