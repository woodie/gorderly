# gorderly v0.4.4

## Fix

The classic-style `Tests Passed: ... (X seconds)` footer and the `-fv`
`Duration` footer summed each leaf's already-rounded elapsed time
(`go test -v`'s own `--- PASS (X.XXs)` lines round to two decimal places),
so a package of sub-millisecond unit tests reported a total of exactly
`0.00s`/`0ms` even when the package genuinely took hundreds of
milliseconds to run. Both footers now sum `PackageResult.Elapsed`
instead, sourced from `go test`'s own `ok <pkg> X.XXXs` package-summary
line -- a single real measurement rather than an accumulation of
already-rounded ones.

## Notes

Purely a total/footer fix -- individual per-leaf times in the tree are
unchanged and still cap out at `go test -v`'s own two-decimal-place text
precision (a real ceiling in its output, not something this release
touches).
