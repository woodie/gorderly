# gorderly v0.4.0

## Fix

Rendered output now puts a blank line before every top-level `Test*`
function, not just once per Go package. Previously, separate top-level
tests within the same package (`TestHumanSize`/`TestTimeAgo`/
`TestDistanceInTime`, say) rendered as adjacent tree branches with
nothing but a dedent between them. Matches `kotidy`'s explicit "blank
line before every top-level suite" rule and `xctidy`'s/RSpec's own
native behavior at their equivalent suite boundaries. (#2)

Cleaned up stale `ginkgo-fd` references left over after the `gomeleon`
rename.

## Dependencies

Bumped to `github.com/woodie/spec` v0.2.0: real `BeforeEach`/`AfterEach`/
`JustBeforeEach` hooks (`Before`/`After` still work, deprecated via
`staticcheck`'s `SA1019`), and the group parameter is now named `context`
by convention rather than `describe`. No behavior change to `gorderly`
itself -- test-suite tooling only.

## Docs

`docs/FRAMEWORK.md` updated for the `BeforeEach`/`AfterEach`/
`JustBeforeEach` hooks above, and now states the `JustBeforeEach` gap
`spec` had before that pickup explicitly -- keeps descriptions concise
(the account-wide rule this release's own test strings follow too).

README restructured to the shared 5-section shape used across
`kotidy`/`xctidy`/`gorderly`, intro rewritten to a single paragraph,
Usage trimmed to a pointer at Output styles, and a Version subsection
added matching `xctidy`'s. `Makefile`'s `test` target now renders with
`-fs`.

## Notes

`gorderly`'s version is a hand-bumped constant (`version.go`), not
derived from `git describe` at build time -- see v0.3.0's release notes
for why.
